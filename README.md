# OCARINA WILD · NUEVO COMIENZO

Versión reiniciada desde cero.

## Regla de diseño
La portada no es un documental entero. Es una **central visual**. Solo cuatro puertas: FAUNA, FLORA, TERRITORIO y ARCHIVO.

La profundidad se abre bajo demanda en paneles. La portada debe poder entenderse sin leer una explicación larga.

## Principios
- Una pantalla principal.
- Cuatro decisiones máximas.
- Fotografía primero.
- Texto corto.
- Profundidad progresiva.
- Evidencia separada de referencia visual.
- Sin acumulación de versiones anteriores.
- Mobile-first.
