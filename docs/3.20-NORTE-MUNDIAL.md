## Ley 3.20

TODO LO IMPORTANTE DEBE PODER VERSE, ENTENDERSE Y RELACIONARSE DENTRO DEL PROYECTO.

Las fuentes pueden originarse fuera, pero su aporte debe quedar representado dentro mediante contexto, crédito, fecha, escala, estado y relación con el registro.

## Sistema

TERRITORIO → RECURSO → FUENTE → EVIDENCIA → REGISTRO → REVISIÓN → RELATO

## Experiencia

- Grandes escenas visuales y recursos gráficos propios.
- Territorios navegables.
- Estados interactivos.
- Fichas progresivas.
- Fuentes explicadas dentro del proyecto.
- Créditos visibles.
- Sistema de evidencia separado de la estética.
- Diseño touch-first.
- Responsive real.
- Accesibilidad y movimiento reducido.
- Sin dependencia de hover.
- Sin convertir la pantalla en un tablero administrativo.

## Regla editorial

Nunca presentar una imagen, fuente o referencia como prueba de presencia local si la fuente no lo demuestra.

## Estándar de datos

La arquitectura toma como referencia requisitos de calidad de ocurrencias y listas de verificación de GBIF/Darwin Core, incluyendo identificadores, nombres científicos, fechas, ubicación, rango taxonómico y metadatos de procedencia/licencia cuando corresponda.

## Accesibilidad

La experiencia adopta WCAG 2.2 como referencia de diseño y QA.

## Recursos visuales

Los cuatro recursos SVG de esta capa son ilustraciones originales de interfaz y territorio. No son fotografías documentales de fauna local y se presentan como tales.

## Regla de fuentes

OCARINA WILD no se comporta como una webgrafía. La fuente se convierte en contenido contextualizado dentro del proyecto; la salida principal no obliga a abandonar la experiencia.

## Congelación

3.20 puede crecer por dentro, pero la regla de experiencia permanece: más sistema no significa más ruido visual.


## REPARADOR PROFUNDO 3.20
La capa 3.20 se considera una experiencia integrada: la persona no debe necesitar abandonar el proyecto para comprender una fuente, su escala, su crédito o su relación con un registro.


## REPARADOR PROFUNDO · CONSOLIDACIÓN 3.20 · 30/09/2026

La versión 3.20 deja de competir con las capas anteriores en la vista pública. El motor, catálogo, inventario, esquema de datos y políticas siguen existiendo como infraestructura; la experiencia pública se concentra en una sola superficie: **Experiencia 3.20**.

### Correcciones estructurales
- Se eliminan visualmente las portadas, manifiestos, estadísticas y bloques territoriales duplicados de la interfaz pública anterior.
- El header conduce a la experiencia 3.20, no a capas antiguas.
- El footer público duplicado se oculta para evitar dos cierres de página.
- Los datos anteriores no se destruyen: permanecen como motor para búsquedas, validación, métricas y futuras integraciones.
- La experiencia incorpora modos TODO / EXPLORAR / TERRITORIO / SISTEMA / FUENTES / NORTE para controlar la dosis de información y evitar una página interminable.
- Las fuentes se abren en fichas internas contextualizadas: crédito, escala, fecha, resumen y función quedan dentro del proyecto; no se usa la fuente como simple lista de enlaces.
- La navegación es táctil, teclado-friendly y no depende del hover.
- Se conserva la distinción DOCUMENTADO / REFERENCIA / PENDIENTE.

### Regla de longitud
**La complejidad no se mide por cuánto se desplaza una persona.** Se mide por cuánto puede hacer el sistema detrás de una interfaz corta.
