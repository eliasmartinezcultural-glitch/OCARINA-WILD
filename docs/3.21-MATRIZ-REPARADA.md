# OCARINA WILD 3.21 · MATRIZ REPARADA

Fecha: 2026-09-30  
Estado: REFORMULACIÓN TRONCAL

## 1. Problema corregido

La versión anterior acumulaba capas que cumplían funciones parecidas:

- portada;
- manifiesto;
- catálogo;
- territorio;
- estatuto;
- sistema;
- fuentes;
- norte;
- navegación por modos.

El problema no era falta de contenido. Era **superposición de funciones**.

3.21 no agrega otra capa. Reasigna cada función a un único propietario editorial.

## 2. Ley 60 / 40 / 100

> **60% INFORMACIÓN · 40% VISUAL · 100% INTERACCIÓN SIMPLE**

### 60% INFORMACIÓN

La información es el contenido principal:

- qué;
- dónde;
- cuándo;
- quién;
- evidencia;
- fuente;
- estado;
- contexto;
- relaciones;
- metodología.

La profundidad no se consigue haciendo una página interminable. Se consigue haciendo que una ficha pueda abrir capas.

### 40% VISUAL

El frente utiliza:

- fotografía documental cuando existe;
- imágenes de referencia identificadas;
- ilustraciones identificadas;
- mapas;
- territorio;
- visualización de datos;
- tipografía;
- color;
- audio o video cuando aporten sentido.

El recurso visual debe tener función: mirar, reconocer, comparar, recordar o comprender.

### 100% INTERACCIÓN SIMPLE

La persona solo necesita acciones obvias:

**buscar · elegir · abrir · seguir · profundizar · volver**

## 3. Matriz única

| Puerta | Pregunta humana | Propietario | No debe duplicar |
|---|---|---|---|
| DESCUBRIR | ¿Qué busco? | catálogo + búsqueda | fuentes, metodología |
| TERRITORIO | ¿Dónde ocurre? | ambientes | fichas completas |
| EVIDENCIA | ¿Qué sabemos? | estados de evidencia | catálogo completo |
| INMERSIÓN | ¿Quiero saber más? | relaciones + fuentes + metodología | portada |

Esta matriz es la pieza central de 3.21.

## 4. Regla de propietario único

Cada información tiene un lugar principal.

Un territorio se define una vez y se reutiliza por relación.

Una fuente se explica una vez y se reutiliza por relación.

Una regla metodológica se define una vez.

Una ficha de especie no vuelve a copiar toda la fuente ni todo el territorio.

El sistema puede mostrar el mismo dato en distintos contextos, pero el contenido no se duplica editorialmente.

## 5. Superficie pública

La página principal contiene solamente:

1. identidad + ley;
2. buscador;
3. cuatro puertas;
4. estado compacto del archivo;
5. cuatro ambientes;
6. tres estados de evidencia;
7. cierre.

No existe una segunda portada, un segundo manifiesto, un segundo catálogo ni un segundo estatuto.

## 6. Profundidad progresiva

La pantalla pública es corta.

La información puede ser extensa mediante:

- resultados de búsqueda;
- fichas;
- diálogos;
- capas;
- relaciones;
- fuentes contextualizadas;
- metodología;
- territorio profundo.

Toda profundidad conserva contexto y una salida clara.

## 7. Modo específico

Si alguien busca una sola cosa, la experiencia debe terminar rápido.

Ejemplo:

**buscar → resultado → ficha → evidencia → volver**

No necesita atravesar territorio, fuentes y metodología.

## 8. Modo inmersivo

Si alguien quiere estudiar:

**ficha → territorio → evidencia → fuente → metodología → relaciones**

Todo sucede dentro de OCARINA WILD.

La experiencia profunda no se convierte en otra web.

## 9. Reglas de no confusión

- evento ≠ población;
- referencia ≠ presencia;
- foto ≠ evidencia;
- distribución ≠ registro local;
- ilustración ≠ fotografía documental;
- fuente regional ≠ fuente local;
- recurso visual ≠ prueba científica.

## 10. Reparación de legado

El catálogo, inventario, estatuto y motor de versiones anteriores no se destruyen.

Permanecen como infraestructura.

La versión 3.21 controla la superficie pública para impedir que esas capas vuelvan a competir entre sí.

## 11. Multidispositivo

La matriz es la misma en:

**320 → 390 → 680 → tablet → notebook → escritorio → pantalla grande.**

La presentación cambia; la arquitectura no.

## 12. Regla final

> **PÁGINA CORTA. INFORMACIÓN PROFUNDA. VISUAL FUERTE. MATRIZ ÚNICA. CERO SUPERPOSICIÓN.**

OCARINA WILD 3.21 no intenta mostrar todo de entrada.

Hace que **todo esté disponible cuando realmente hace falta**.
