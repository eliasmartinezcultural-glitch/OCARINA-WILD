# OCARINA WILD 2.0 — ARQUITECTURA TRONCAL

## Idea
Complejidad interna + simplicidad externa.

La interfaz debe sentirse como explorar un mundo vivo: tocar, descubrir, abrir, observar y volver.

## Capas
1. Constitución conservacionista: el Estatuto Universal de Respeto a la Vida es la norma interna superior.
2. Datos de biodiversidad: registros separados de interfaz, preparados para Darwin Core.
3. Motor de política: valida evidencia, procedencia visual y sensibilidad antes de renderizar.
4. Estado de aplicación: un único estado central desacoplado del contenido.
5. Motor de interfaz: componentes, diálogos, accesibilidad, fallbacks y mobile-first.
6. Experiencia: descubrimiento progresivo y microinteracciones sin convertir la pantalla en software científico.

- Datos sensibles: las ubicaciones sensibles deben generalizarse u ocultarse cuando corresponda. citeturn0search1
- Accesibilidad: objetivo WCAG 2.2 AA. WCAG 2.2 es un estándar internacional y fue aprobado como ISO/IEC 40500:2025. citeturn0search2turn0search12
- Conservación: se toman como referencia marcos internacionales, sin presentar el Estatuto interno como ley internacional.

## Principio de producto
VER → TOCAR → DESCUBRIR → ENTENDER → RECORDAR → CUIDAR.

El código debe poder sostener datos, fuentes, taxonomía, observaciones, sensibilidad, multimedia, accesibilidad y evolución futura sin aumentar innecesariamente la carga cognitiva.

## Fases
A. Motor modular.
B. Evidencia y procedencia.
C. Territorio y temporadas.
D. Observación comunitaria.
E. Archivo y exportación estructurada.
F. Experiencias interactivas subordinadas al Estatuto.

## Regla de oro
Si una función aumenta la complejidad visible sin aumentar conocimiento, interacción significativa o conservación, no entra.
